AdaptixC2 Adversarial emulation framework

AdaptixC2 is ​​an extensible post-exploitation and adversarial emulation framework made for penetration testers. The Adaptix Server is written in Golang and to allow operator flexibility. The GUI Client is written in C++ QT, allowing it to be used on Linux, Windows, and MacOS operating systems.

Legal Warning

This tool is designed for AUTHORIZED security testing and red team operations ONLY. Unauthorized use is strictly prohibited and may violate local and international laws. Use at your own risk. Features

Server/Client Architecture for Multiplayer Support Cross-platform GUI client Fully encrypted communications Listener and Agents as Plugin (Extender) Task and Jobs storage Files and Process browsers Credentials, Targets and Screenshots Managers Socks4 / Socks5 / Socks5 Auth support Local and Reverse port forwarding support BOF support Linking Agents and Sessions Graph Agents Health Checker Agents KillDate and WorkingTime control Windows/Linux/MacOs agents support Remote Terminal / Shell AxScript Engine
